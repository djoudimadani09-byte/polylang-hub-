# مجمع بوليلانغ للترجمة المعتمدة والمؤتمرات الدولية | Polylang Hub

مجمع بوليلانغ للترجمة المعتمدة والمؤتمرات الدولية وفق أرقى معايير الجودة الدولية **ISO 17100:2015**.

## ✨ المميزات الرئيسية للمنصة:
- 📜 **الترجمة القانونية والمحلفة**: ترجمة العقود والمستندات الرسمية مع الختم المعتمد المقبول لدى السفارات والوزارات.
- 🎙️ **الترجمة الفورية للمؤتمرات**: تجهيز القمم والمؤتمرات الدولية بكابينات الترجمة العازلة للصوت ISO 4043 وسماعات الراديو الرقمية اللاسلكية.
- 🎬 **محرر الترجمة المرئية (SRT Studio)**: محرر مرئي مباشر لضبط التوقيت وتصدير ملفات `.srt` متوافق مع معايير Netflix العالمية (20 CPS / 42 CPL).
- 🎓 **أكاديمية بوليلانغ للماستركلاس**: ورشات تدريبية متقدمة مع إصدار شهادات إتمام معتمدة قابلة للتحقق.
- 💳 **باقات الأسعار والدفع الإلكتروني**: دعم الدفع بالدينار الجزائري (بريدي موب / البطاقة الذهبية / CIB) والعملات الدولية (PayPal / Visa / MasterCard).
- 🌐 **دعم كامل للغتين**: العربية والإنجليزية مع التبديل الفوري بين RTL و LTR.

## 🚀 النشر على GitHub Pages:
يحتوي المستودع على ملف `index.html` في المسار الجذري (`/`)، مما يتيح تشغيله كموقع ويب تفاعلي وتطبيق ويب متكامل عبر **GitHub Pages** فوراً على الرابط:
`https://djoudimadani09-byte.github.io/`
